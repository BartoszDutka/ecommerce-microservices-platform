# E-commerce Microservices Platform

A multi-service e-commerce system with a Backend for Frontend (BFF) and a Flutter mobile client.

## Features

- Product browsing and cart workflows
- BFF aggregation of backend APIs
- BLoC-based mobile architecture
- read-only offline product cache
- Docker Compose orchestration

## Technology stack

C#, .NET, Flutter, Dart, SQLite, MongoDB, RabbitMQ, Docker Compose.

## Getting started

Review `docker-compose.yml` and `run.ps1` before starting the backend; configure fresh development credentials. For the mobile client, see the existing [Flutter documentation](ZTP4/README.md), configure the BFF address, install Flutter dependencies and run the app on a supported emulator or device. Existing component names are retained in the repository.
